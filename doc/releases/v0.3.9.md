# FM4 v0.3.9 - Native PC Port (Windows x64)

## Changes since v0.3.8

- Switched to the Vulkan renderer.
- Added Low, Medium, High and Custom graphics presets:
  - **Low:** 1x rendering, 4x anisotropic filtering, FSR.
  - **Medium:** 2x rendering, 8x anisotropic filtering, FSR.
  - **High:** 2x rendering, 16x anisotropic filtering, bilinear output.
- Kept the guest video resolution at 720p while allowing independent render scaling and output scaling.
- Simplified preset descriptions: only the selected preset's settings appear below it.
- Added an anisotropic filtering dropdown and a VSync toggle.
- Updated render-scale labels: 1x 720p, 2x 1440p, 3x 4K and 4x 5K.
- Corrected the separate host presentation limit that kept the 120 FPS mode capped at 60 FPS.
- Replaced the showroom camera's fixed time step with elapsed time to prevent accelerated car presentations at 120 FPS.
- Added explicit fullscreen and presentation cleanup on exit to address desktop HDR dimming.
- Ported Vulkan depth-bias handling from Xenia Canary.
- Removed the legacy patch that disabled exterior shadow maps and disabled three FH1-specific rendering shortcuts while investigating under-car artifacts.
- Added Automatic, Stereo and 5.1 PCM audio output selection.
- Added automatic Forza Plus 120 FPS physics-profile switching, with restoration of the previous profile when returning to 60 FPS.
