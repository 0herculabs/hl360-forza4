# FM4 v0.3.11 - Native PC Port (Windows x64)

## Changes since v0.3.10

### Cheats
A new **Cheats** tab in the launcher. Its options apply from the next game start:
- **Set credits at start** sets the active profile's credits to the chosen amount, up to 20,000,000. The game lowers anything above that when it loads a profile. While the option is on, the amount is set again at every start, so credits earned or spent since the last start are replaced. Turn it off once you have the amount you want.
- **Unicorn cars** puts in the dealer the 17 cars that were only gifts on the Xbox 360, such as the Ferrari F430 Scuderia, the Honda NSX-R GT and the Toyota Supra Top Secret. They appear under their make in Cars > Buy Cars, at their normal price.

Back up your profile before using cheats.

### Fixes
- Closing the game window no longer leaves a frozen window behind (issue #30). If shutdown is still running after 3 seconds, the process ends.
- The launcher no longer freezes when a USB or Bluetooth device is slow to answer Windows. The controller list now loads in the background, and the Wheel tab says so while it waits.
- Pressing Play no longer waits for the controller list to finish loading.
